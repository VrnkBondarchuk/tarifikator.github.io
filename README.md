# Тарификатор

Статическая страница проекта: [открыть сайт](https://vrnkbondarchuk.github.io/tarifikator.github.io/).

GitHub Pages публикует содержимое корня ветки `main`. Для обновления сайта из этой папки:

```bash
git add -A
git commit -m "Update site"
git push origin main
```

Точка входа — `index.html`; стили, шрифты и изображения лежат в `css/`, `fonts/` и `assets/`.
