Как это работает

«Тарификатор» помогает готовить отчёты, следить за педагогической нагрузкой и оперативно обновлять её у учителей в конкретных классах. Сервис считает нагрузку по предметам, курсам и внеурочной деятельности, учитывает вакантные часы и формирует ведомости для тарификации и комплектования.

Помогает сдать тарификацию без долгих перепроверок

В «Тарификаторе» директор распределяет часы между учителями и классами. Он видит, кому не хватает часов до нормы, а где открывать вакансию. Сервис помогает всем, кто работает с нагрузкой: директору и заместителям — для подготовки к тарификации, кадровикам — для расчёта зарплат, диспетчеру по расписанию — для организации сетки уроков.

Наглядная нагрузка по каждому преподавателю

Сервис даёт контроль над нагрузкой преподавателей. По фамилии можно посмотреть нагрузку в конкретных классах, проверить классное руководство и заведование кабинетом.

«Тарификатор» показывает вакантные часы, отмечает педагогов с неполной ставкой, а при подборе предлагает специалистов из нужной предметной области. Сервис не ограничивает выбор, поэтому директор может учитывать предпочтения учителей по классам.

Гибкие учебные планы

«Тарификатор» собирает учебные планы для каждой параллели и рассчитывает общую нагрузку школы. Он учитывает количество классов и деление на подгруппы, например, для занятий по иностранному языку. Можно сформировать индивидуальные учебные планы для детей на домашнем обучении и классов коррекции. В результате директор видит, сколько часов приходится на каждый предмет, курс и внеурочную деятельность.

Утверждённые учебные планы можно скачать, чтобы распечатать или опубликовать на сайте школы. При любых изменениях достаточно скачать актуальную версию и заменить прежнюю.

Подсказки для быстрого распределения

Сервис помогает перераспределить часы с учётом текущей нагрузки. Назначить часы можно двумя способами: отдельно в каждом классе или по предмету для всей параллели разом.

«Тарификатор» находит нераспределённые часы и классы без нагрузки, а при подборе предлагает специалистов из нужной предметной области. Сервис не ограничивает выбор, поэтому директор может учитывать предпочтения учителей по классам.

Сводная ведомость — в один клик

Когда директору нужно будет согласовать нагрузку с учителем, сервис сформирует заявление со сводной ведомостью. «Тарификатор» автоматически укажет в документе ФИО педагога, предметы, классы и часы. Файл можно распечатать, подписать и передать в отдел кадров.
